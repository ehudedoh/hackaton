# JuriLex

Application d’aide à la lecture de documents, en français simple et en éwé.

## Étape actuelle

Interface frontend (étape 1). L’OCR, l’analyse IA et la voix ne sont pas encore branchés.

## Lancer l’interface

```bash
cd frontend
npm install
npm run dev
```

Puis ouvrir l’adresse affichée, en général `http://localhost:5173`.
